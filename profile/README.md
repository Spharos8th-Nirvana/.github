# NIRVANA

**한국 사찰 체험 프로그램 예약 플랫폼**

NIRVANA는 한국의 사찰과 이용자를 연결하여 다양한 사찰 체험 프로그램을 탐색하고 예약할 수 있도록 돕는 플랫폼입니다.

## Project Overview

- 사찰별 정보 및 체험 프로그램 제공
- 프로그램 검색 및 예약
- 결제 및 예약 관리
- 커뮤니티 및 알림 서비스
- 사찰 방문 인증 및 여권 서비스

## Architecture

NIRVANA는 서비스별 독립적인 책임과 확장성을 고려하여 MSA 기반으로 구성합니다.

## Tech Stack

- **Backend:** Java, Spring Boot
- **Frontend:** React, Next.js, TypeScript
- **Infrastructure:** Docker, Kafka
- **Database:** MySQL, MongoDB

## Repositories

각 서비스의 코드는 서비스별 Repository에서 관리합니다.
